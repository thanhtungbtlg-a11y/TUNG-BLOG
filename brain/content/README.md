# README

This vault was generated from `combined_visual.docx`.

## Structure

- `pages/`: 106 Markdown files, one per Word/OCR page.
- `assets/`: 106 extracted page images.
- `00_Index.md`: navigation index.
- `pages/Page 001.md` through `Page 106.md`: sequential reading notes with Obsidian embeds.

## How to use

1. Unzip the `.zip` file.
2. Open Obsidian.
3. Choose **Open folder as vault**.
4. Select `LEED_Core_Concepts_Word_PageMarkdown_Obsidian`.
5. Start from `00_Index.md`.

The OCR text is copied page-by-page from the Word file. The page image is kept above the text so you can visually compare the OCR with the original layout.
