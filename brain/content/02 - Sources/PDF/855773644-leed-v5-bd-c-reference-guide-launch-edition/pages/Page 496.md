PATH 4. DAYLIGHT SIMULATION (1–4 POINTS)


Perform a daylight simulation analysis for the project to understand and optimize access to
daylight and visual comfort. Use the calculation protocols in _IES LM-83-23_ with the following
clarifications:


  - Calculate s patial daylight autonomy300/50% (sDA300/50%) and annual sunlight
exposure1000,250 (ASE1000,250) as defined in _IES LM-83-23_ for each regularly occupied
space in the project. sDA 150/50% may be used for areas without visual tasks with design
targets of 225 lux.

  - For any regularly occupied spaces with ASEnet(1000,250h) greater than 20%, identify how the
space is designed to address glare.

  - Calculate the average sDA 300/50% or sDA 150/50% for the total regularly occupied floor area.
Do not exclude spaces based on ASE. Points are awarded based on this calculation,
according to Table 2.

Table 2. Points for d aylight simulation

|Average sDA300/50% or sDA150/50% value|Points|
|---|---|
|≥ 40%|1|
|≥ 55%|2|
|≥ 65%|3|
|≥ 75%|4|
