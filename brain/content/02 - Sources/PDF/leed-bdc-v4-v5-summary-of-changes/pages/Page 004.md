<td>

<li>Incorporated into new credit: Electric Vehicles.</li>
<li>Electric vehicle charging is incorporated into new credit: LTc Electric Vehicles Option 1 which modified the referenced standards and code electrical connectors must comply with, modified point thresholds, increased the minimum number of EVSE parking spaces, and added requirements for accessible EVSE parking space.</li>
<li>EVSE point thresholds and number of spaces are differentiated for commercial and residential parking.</li>
<li>Removed liquid, gas or battery facilities option.</li>
</ul>
